# MovieVault

## Project Description

MovieVault is a movie watchlist website where users can keep track of movies they want to watch or have already watched. Users can add movies by entering the movie title, genre, release year, and watch status.

The website displays the movies in a table and shows the total number of movies added.

## Features

- Homepage with navigation
- Add Movie form
- Movie watchlist table
- Movie counter
- Form validation
- Browser storage using localStorage

## Technologies Used

- HTML
- CSS
- JavaScript

## How to Run

1. Download the project files from GitHub.
2. Open the project folder.
3. Open index.html in Google Chrome.
4. Click Add Movie to enter a movie.
5. Click Save Movie to add it to the watchlist.
